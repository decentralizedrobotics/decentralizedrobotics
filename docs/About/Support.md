# Support

## Sponsor early access

DeRo early access is available to Ranch Hand Robotics LLC sponsors. You can support Ranch Hand Robotics LLC through:

* [GitHub Sponsors](https://github.com/sponsors/ranch-hand-robotics)

DeRo is in early development. Tools, interfaces, and setup instructions are evolving; the onboarding and developer guides include planned workflows and Coming Soon features, not a production-ready setup.

If you are a sponsor, [request early access using the repository's Request Access issue template](https://github.com/decentralizedrobotics/decentralizedrobotics/issues/new?template=request-access.md&title=Request+Access). Include only your GitHub handle and a brief, non-sensitive description of your intended use case.

Access requests are public. **Do not post payment details, receipts, private keys, tokens, or other secrets.**
